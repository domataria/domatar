# Security

If you believe you have found a vulnerability in Domatar, please report
it privately. Do not open a public issue, pull request, or discussion
that includes exploit details.

**Preferred:** GitHub Security Advisories on this repository
(Security → Advisories → New draft security advisory), or the
equivalent private reporting channel on the project that published
the tree you cloned.

Include:

- Affected component (platform, app id, or spec PART)
- A description of the issue and its impact
- Steps or a proof of concept you are willing to share privately

We will acknowledge the report and work on a fix before any public
disclosure.

Operational keys, genesis vaults, and database dumps must never be
committed. Development Compose passwords are labeled defaults only;
change them before exposing a node.
